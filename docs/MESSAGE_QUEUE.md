# 📬 Система умных очередей сообщений

## Обзор

Новая система очередей обеспечивает быструю, надежную и интеллектуальную доставку уведомлений без превышения лимитов Telegram API.

## 🎯 Основные возможности

### ✅ Что реализовано:

1. **Приоритетная очередь**
   - HIGH: Сигналы с OI ≥ 10%
   - NORMAL: Сигналы с OI 5-10%
   - LOW: Сигналы с OI < 5%

2. **Rate Limiting**
   - Глобальный лимит: 28 сообщений/сек (безопасная граница от 30 msg/sec Telegram)
   - Per-chat лимит: 28 сообщений/сек на пользователя
   - Sliding window: 1000ms

3. **Дедупликация**
   - Окно дедупликации: 5 секунд
   - Предотвращает отправку идентичных сигналов
   - Ключ: `{chatId}:{symbol}:{roundedOI}`

4. **Retry логика**
   - Максимум 3 попытки отправки
   - Автоматический retry при ошибках
   - Drop после исчерпания попыток

5. **Автоматическая очистка**
   - Cleanup каждые 60 секунд
   - Удаление устаревших данных
   - Предотвращение утечек памяти

## 🔧 Конфигурация

### Переменные окружения:

```bash
# TriggerEngine настройки
TRIGGER_ENGINE_FLUSH_MS=50              # Задержка обработки (default: 50ms)
MIN_CHECK_INTERVAL_MS=100               # Интервал проверки триггеров (default: 100ms)
TRIGGER_ENGINE_METRIC_CACHE_TTL_MS=500 # TTL кэша метрик (default: 500ms)
BATCH_PROCESSING_SIZE=10                # Размер батча (default: 10)

# Debug (опционально)
DEBUG_TRIGGER_ENGINE=true               # Включить debug логи
```

### Настройки MessageQueueService (в коде):

```typescript
MAX_MESSAGES_PER_SECOND = 28;     // Per-chat лимит
GLOBAL_MAX_PER_SECOND = 28;       // Глобальный лимит
RATE_LIMIT_WINDOW_MS = 1000;      // Окно rate limit
DEDUP_WINDOW_MS = 5000;           // Окно дедупликации
MAX_QUEUE_SIZE = 1000;            // Максимальный размер очереди
MAX_RETRY_COUNT = 3;              // Количество попыток
PROCESSING_INTERVAL_MS = 50;      // Интервал обработки
```

## 📈 Мониторинг

### Статистика очереди:

Бот автоматически логирует статистику каждые 5 минут:

```
📊 Queue stats: Sent=1234, Dropped=0, Dedup=45, Queue=[H:2 N:5 L:1]
```

### Метрики:
- **Sent**: Успешно отправленные сообщения
- **Dropped**: Отброшенные после retry
- **Dedup**: Дедуплицированные сигналы
- **Queue**: Размер очередей [High:Normal:Low]

## 🚨 Troubleshooting

### Сообщения задерживаются:
1. Проверить размер очереди: `getQueueSize()`
2. Проверить статистику: `getStats()`
3. Увеличить `PROCESSING_INTERVAL_MS` для меньшей нагрузки

### Слишком много дедупликаций:
1. Уменьшить `DEDUP_WINDOW_MS` (default: 5000ms)
2. Проверить логи для понимания паттернов

### Rate limit exceeded:
1. Проверить количество активных пользователей
2. Уменьшить `MAX_MESSAGES_PER_SECOND` для большей безопасности
3. Проверить логи Telegram API
